Entry for the [make.fun bounty "Name the Robot Band"](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74): one funny name for a band made of robots, plus a few words on its hit song, all under 200 characters.

## Entry

> The Infinite Loops — hit single 'While (True) I Love You'.

The band name is a real-sounding robot band; the hit song turns the band's defining flaw — an endless loop — into the love song it cannot escape.

## How it works

`main.ts` (Node stdlib only) builds the entry from its named parts, checks the gate (1–200 characters, one line, non-blank), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back and verifies the sha256. The output is deterministic — the same text on every run.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
```
